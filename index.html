How this dashboard works
Data refreshes automatically from each cluster's Jira filter twice per business day (8am and 4pm ET). The "data as of" indicator shows the latest refresh — green if fresh, amber if stale, red if auto-refresh is failing. Daily snapshots accumulate into the trend chart over time.
What is this?
This is a dashboard for support escalations. It visualizes delivery teams' progress toward resolution of escalated work to inform and prepare leadership and customer-facing teams.
